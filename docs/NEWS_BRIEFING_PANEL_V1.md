- 시작점: feat/nh-integration-v2 @ 9f7efa1325387468312c6f99dc7b360ee2777091
- 기존 분리 브랜치 feat/news-briefing-archive-isolated의 두 순수 JS 모듈과 테스트를 변경 없이 복사

- 운영 main, release/pages, PR #7, GAS, Sheets, Properties 및 NH 계좌 기능/실계좌 호출은 **변경하지 않음**

이 단계는 **ChatGPT 예약 작업 결과의 07:00 자동 배달을 구현한 것이 아니다.**
ChatGPT 예약 작업→GitHub Pages/GAS로 자동 전송되는 인증된 경로는 아직 없다.
현재는 PC 또는 휴대폰에서 공개용 JSON 파일을 사용자 동작으로 가져와서 조회·백업한다.

## 사용법 (운영 배포가 아닌 격리 개발 버전 기준)

1. 뉴스 메뉴(#/news)의 "오전 7시 투자 브리핑 보관함"을 연다.
2. "JSON 가져오기"로 public-only schema v1 백업 파일을 선택한다. 오류 시 기존 보관함은 보존한다.
3. 보고서 날짜·선언된 작성 경로를 선택하여 읽는다. 생성·관측·조회 시각이 불명확하면 미확인이라고 표시한다.
4. "JSON 백업 내보내기"로 브라우저 내 브리핑만 별도 백업한다.
5. 이전 페이지에 직접 붙여넣은 기록이 있으면 "기존 수동 브리핑 복사"를 누른다. 원본(localStorage)은 유지하며 **자동 마이그레이션하지 않는다**.

두 저장소는 별개다.
- 기존 수동 기록: myinvest_public_ai_briefings_v1 (기존 코드 그대로)
- 새 공개 보관함: myinvest_public_briefing_archive_v1

새 보관함은 현재 사용 중인 브라우저의 localStorage를 사용한다.
따라서 **PC·모바일·다른 브라우저에 자동 공유되지 않는다.** 계좌번호/잔고/비밀값 등 개인·인증 정보는 JSON에 넣지 않는다.

## 안전 속성

- 가져오기/내보내기/기존 기록 복사는 사용자 클릭으로만 실행
- 3MB 파일 크기 제한, 90건 제한, 엄격한 스키마/시간/출처/민감정보 형식 검증
- 저장본 오류나 잘못된 가져오기에서 기존 자료를 지우거나 복구라고 주장하지 않음
- 동일 날짜·작성 경로에서는 선언된 생성시각이 더 늦은 기록만 자동 교체. 동일 시각 내용 충돌은 기본적으로 기존 보존
- 기존 수동 기록의 저장 시각(at)을 ChatGPT 생성시각으로 취급하지 않음
- 사용자 제공 본문은 textContent로만 표시, 원문 URL은 HTTPS 검사 후 rel=noopener noreferrer
- 클릭만으로 NH/GAS/시장 API 호출, 주문, 정기 타이머, 외부 자동송신 없음
- 'chatgpt-task' 선언은 신원 증명 아님; 시장 수치·기사 출처는 실시간 검증된 것으로 표기하지 않음

## 이후 남은 과제

1. 실제 Node/브라우저 회귀 테스트 및 Fold6 화면 배치 확인

3. 자동화 저장 경로 결정: 별도 승인된 공개시장 데이터 수집·브리핑 생성 파이프라인 + 읽기 전용 정적 JSON/공개 GAS(계좌 권한 분리) 등
4. 자동 저장·PC/모바일 동기화 전에 승인된 저장소의 서명/접근범위/개인정보/배포보안을 검토
