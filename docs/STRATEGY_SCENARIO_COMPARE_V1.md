# MY INVEST V2 — 단타·스윙 가상 투자 시나리오 비교 화면 V1

## 목적·격리 범위

Codex가 개발 중인 NEWS/브리핑 PR #8, 기존 `js/page-strategy.js`, `index.html`, NH/GAS 및 운영 자산을 수정하지 않고 **신규 파일만** 추가했습니다.

- 작업 브랜치: `feat/strategy-scenario-compare-isolated` (기반: `feat/strategy-risk-capacity-isolated`)
- 계산 엔진: `js/strategy-scenario-compare-v1.js` (순수 함수)
- 화면: `js/strategy-scenario-compare-panel-v1.js` (독립 DOM 컨테이너 마운트, 안전한 텍스트 출력)
- 미리보기: `preview/strategy-scenario-compare-v1.html` (로컬 정적 페이지, 별도 운영 배포 없음)
- 단위 테스트: `tests/strategy-scenario-compare-v1.test.cjs`
- PC/모바일 브라우저: `tests/browser_strategy_scenario_compare_v1.py` (Playwright, 합성 기본값만 사용)

## 사용자 흐름

1. 시장(KR/KRW, US/USD) 선택. 한국에서 미국으로 전환할 경우 숫자는 자동 환전되지 않으며 해당 통화의 가상 숫자로 다시 작성해야 합니다.
2. 공통 투자자본, 가용 현금, 이미 배분된 금액, 기존 미청산 위험, 편도 수수료·슬리피지(bp), 거래 단위를 입력합니다.
3. 단타와 스윙 각각 진입가·손절가·목표가·요청 위험예산·요청 투자 배분·급락 스트레스(손절가 아래 체결 비율)를 입력합니다.
4. 두 계획을 **각자 같은 공통 자본에 대하여 독립적으로** 평가합니다. 합산 자산/투자비중이나 두 포지션의 동시 개설로 해석하지 않습니다.
5. 모드별 가상 수량, 진입 비용, 손절 손실, 스트레스 손실, 목표 이익, 비용 반영 손익비를 나란히 표시합니다.
6. 두 시나리오 모두 정책을 통과하면 '스윙 − 단타' 차이만 계산합니다. 한쪽이 유효하지 않으면 두 계획의 숫자 차이를 표시하지 않습니다.

## 계산 범위·제한

- 기존 `strategy-risk-capacity-v1.js`를 호출하며 재구현하지 않습니다.
- 단타 기본 상한: 위험예산 자본의 1%, 종목 비중 20%, 최소 가정 손익비 1.5:1.
- 스윙 기본 상한: 위험예산 자본의 1.5%, 종목 비중 25%, 최소 가정 손익비 2:1.
- 사용자 입력의 편도 수수료 및 슬리피지를 반영합니다. 단일 스트레스 급락폭을 가정해 수량을 별도로 제한합니다.
- 자본, 가용 현금, 배분, 기존 미청산 위험은 **같은 통화**로 주어야 하며 KRW/USD 혼합은 거부됩니다.
- 초기 진입가·손절가·수익목표는 **합성 예시**이며 현재 시세나 사용자 계좌/보유 수량이 아닙니다.
- 주식 정수 수량의 가상 롱 포지션만 계산합니다. 실제 시장의 호가, 세금, 환율, 종목별 주문 최소단위, 실체결, 거래소 휴장, 손절 미체결 위험을 인증하지 않습니다.
- 시장 시간 문구에는 기기 현재 시각을 사용하지만, 실제 시장 개장·실시간 가격·원천 관측일은 확인하지 않습니다.
- 실제 주문, 매도·매수 승인, AI 종목 추천, 증권사 계정, 저장, 외부 HTTP 요청은 없습니다.

## 오류·보안 처리

- 모델에서는 모든 입력 스키마를 엄격히 제한합니다. 계좌번호·보유종목·인증정보·주문 입력 필드가 추가되면 계산 자체를 거부합니다.
- 필수 숫자 빈칸은 `NaN`으로 처리하며 0으로 오인하지 않습니다.
- 단일 모드가 잘못되면 다른 모드 계산은 유지하지만 비교 차이 값은 내지 않습니다.
- 화면은 `textContent`와 `createElement`만 사용하며 사용자 원문을 `innerHTML`로 삽입하지 않습니다.
- 화면 새로고침·초기화 시 합성 기본값으로 돌아갑니다. `localStorage` / `sessionStorage`에 입력을 기록하지 않습니다.
- 계산기 결과에 `tradeApproved`, `canPlaceOrder`, `marketDataVerified` 등 주문·원천 인증 상태는 false입니다.

## 테스트

- 비교 계산 단위 테스트 18개: 모드 간 대안 독립성, 투자금 상한, 급락 스트레스, 손익비, 누락·비공개 입력 방어, 통화 분리.
- Playwright 테스트: 1440px(PC), 690px(접은 태블릿/중간 화면), 344px(좁은 Fold 화면)에서 필드·결과·오류·초기화·overflow 확인.
- 선행 시장데이터/거래시간/위험관리 97개 테스트도 같은 워크플로에서 재실행.
- 코드 작업 및 브라우저 검증은 합성 데이터/정적 HTML에서만 진행하며 실제 NH/GAS/Sheets/Properties에 접근하지 않습니다.
