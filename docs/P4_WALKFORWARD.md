# MY INVEST V2 — P4 고정 규칙 시계열 분리·워크포워드 사후검증

## 범위

- **독립 모듈**: `js/strategy-walkforward-v1.js`
- **독립 테스트**: `tests/strategy-walkforward-v1.test.cjs`
- 브랜치: `feat/p4-strategy-evaluation-isolated`
- 기존 P4 시계열 품질검사, 스윙 백테스트, 거래장부 재검증을 읽기 전용으로 재사용
- 중계 Worker, GAS, 실제 NH 시세·잔고, `js/page-*.js`, 운영 및 개발 Pages **수정하지 않음**

## 목적과 엄격한 해석

‘워크포워드’라고 부르더라도 이 버전은 학습·최적화가 아니라 **이미 고정된 단일 규칙의 시간순 전진 재평가**다.

- 평가 구간 끝까지의 확정 일봉만 각 테스트에 전달한다. 미래의 종가나 다음 구간의 결과로 과거 신호를 만들지 않는다.
- 모든 구간은 **같은 고정 전략 파라미터**를 사용한다. 데이터에 맞춰 우수 파라미터를 검색하지 않는다.
- 각 구간 직전 데이터는 지표 계산용 선행 관측값으로 제공하지만 모델을 학습하거나 파라미터를 재최적화하지 않는다.
- 사용자가 이미 전체 과거 수익률을 보고 파라미터를 선택했는지는 프로그램이 증명할 수 없다. 따라서 `independentHoldoutProven:false`, `parametersPreRegistered:false`.
- 고정 구간 2~6개로 나누고, 평가 구간은 중복하지 않으며, 마지막 데이터까지 **모든 봉을 포함**해야 한다. 선택적으로 성과가 낮은 마지막 구간을 제외하는 식의 편향을 차단한다.

## 입력 및 예

```js
const api=require('./js/strategy-walkforward-v1.js');
const result=api.evaluate({
  now: Date.now(),           // 실제 운용 시 관측시각 확인. 이 파일은 API를 호출하지 않음.
  series: {
    market:'US',currency:'USD',exchange:'NASDAQ',symbol:'SERV',
    finalized:true,interval:'1d',sourceProvider:'DECLARED_SOURCE',
    priceConvention:'split_adjusted',purpose:'historical',
    observedAt: /* 원천 관측 Unix milliseconds */,
    bars: [/* 240개 완결 일봉: {t,o,h,l,c,v} */]
  },
  trainBars:120,evalBars:40,foldCount:3,
  strategy:{riskPct:1,maxAllocationPct:25,feeBps:10,slippageBps:10,targetR:2}
});
```

120 + 40×3 = 240개의 확정 일봉을 사용한다. 각 구간은 다음처럼 구성한다.

| 구간 | 사용할 수 있는 과거 데이터 | 실제 평가 구간 | 제한 |
|---|---|---|---|
| 1 | 0~119 | 120~159 | 159 이후 데이터 접근 금지 |
| 2 | 0~159 | 160~199 | 199 이후 데이터 접근 금지 |
| 3 | 0~199 | 200~239 | 239 이후 데이터 접근 금지 |

구간 첫 시가에서 체결된 거래는 바로 전 거래일 마감 시점에 발생한 신호를 사용해 진입할 수 있다. 이전 구간의 손익과 보유 포지션은 이월하지 않는다.

## 결과

- 구간별 시작·종료일, 평가봉 수, 고정 파라미터 사용 여부
- 구간별 거래 횟수, 순손익, 순수익률, 승률, 평균 R, 일별 종가 가상청산 기준 최대낙폭, 수수료, 계획 위험예산 초과 거래
- 전체 구간 중 순손익 양수 구간 수, 거래가 없었던 구간 수, 각 구간 수익률의 평균·중앙값·최저/최고, 종료일 강제청산 수
- 평균 구간 수익률은 **연속 운용 복리 수익률이 아님**. 구간마다 초기자본이 초기화되므로 수익률을 기하연결하지 않는다. `totalCompoundedReturnPct:null`로 표시.
- 구간 종료일에 기존 P4 엔진이 미청산 포지션을 `end_of_sample`로 종료한 경우 `forcedEndOfFoldLiquidations`로 명시한다. 이는 실제로 다음 거래일까지 보유한 것과 다를 수 있다.
- 거래 수가 30건 미만이면 표본 부족 경고. 30건을 넘겨도 독립된 수익성 검증이 되지는 않음.

## 검증 및 출시 경계

- 별도 P4 품질검사에서 `structurally_ready`가 아니면 실행하지 않는다.
- 각 구간은 오직 해당 구간 종료 시점까지의 배열 접두부를 기존 P4 백테스트에 넘긴다. 같은 입력으로 P4 리뷰 엔진이 거래 장부와 손익을 재검증하지 못하면 전체 결과를 차단한다.
- 증권사/무료 시세 제공자의 종목 코드·배당/분할 수정·휴장/거래정지·상폐/생존편향 등 진위는 별도로 검증해야 한다.
- 실시간 신호 또는 실제 거래, AI 투자 추천, 미래 수익률이나 독립 외표본 성과로 표시할 수 없다.
- 실제 공개 시세 연결, 화면 표현, 폴드6 실기기 테스트, 배포와 운영 병합은 기존 Codex 작업이 끝난 후 별도 승인·통합해야 한다.

이 문서는 **Codex 지시문이 아니며**, 사용자가 요청하기 전까지 통합 지시를 발송하지 않는다.
