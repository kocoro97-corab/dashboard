# MY INVEST V2 — Galaxy Z Fold6 개발 사이트 실측·후속 검증 (2026-11-25)

## 근거 및 범위
- 사용자가 직접 개발 Pages 게시 후 Fold6에서 접힌/펼친 화면과 메뉴를 검사하고, 로그인 세션의 익명화된 진단 JSON을 제공함
- 개발 프런트엔드 게시 소스: `69d07a2c5c5c3d2b6d18697ac45cad70858644ab`; 게시 커밋: `7739914383f69208b45b414153fd852e1c3fef01`
- 기기 실측 1회. 별도의 PC 실측, 개선 전/후 동일조건 비교, NH 실제 자산 정합성은 수행하지 않음
- 진단 메타데이터만 요약. 토큰, 계좌번호, 보유금액, 요청 URL, 원문 응답, 개인 설정은 기록하지 않음

## 완료된 사용자 관측
- 로그인/홈, 글로벌 시장, 산업·테마/투자전략, 뉴스·캘린더, 계좌관리, Fold6 접힘·펼침, 성능 측정: 사용자 화면 조작 확인 7/7
- 화면 `ready`/`mounted`는 **UI 수명주기**만 나타내며 가격·뉴스·계좌 데이터 수신 완료의 증거가 아님
- `settings` 화면은 제공된 진단에서 `NOT_VISITED`; 체크리스트 7/7과 별도
- AAPL 5분봉 실연결 검사 `NOT_RUN`, 국내 5분봉·실계좌·외부계좌 저장/복구·공개 브리핑 검사는 `NOT_CONNECTED`
- 개발용 계좌 기능의 실제 NH 조회/수정/복구를 사용자 UI 조작 통과로 기록하지 않음

## 측정 및 장애 징후
- 문서 DOM 준비 146ms, load 148ms, FCP 132ms
- 관측한 리소스 총 195건, `/js/` 요청 86건, OCR 1건, 미국 종목 디렉터리 1건 (전체 세션 관측으로 로그인 전 요청과 혼동하지 않기)
- 홈 메뉴 전환 완료 33,862ms; 계좌관리 완료 표본의 최대 23,524ms. 다른 계좌관리 완료 표본은 주로 6~14ms. `cancelled`인 111,827ms 섹터 샘플을 성공 처리 시간으로 계산하면 안 됨
- `RELAY_BUSY` / HTTP 503이 섹터·시장·뉴스·계좌 화면에 반복 보고됨
- `READ_NETWORK` 및 `NH_NO_PRICE` 일부는 `RECOVERED`; `GAS_REJECTED`, `FRONTEND_NETWORK`도 보고됨
- 로그인 세션 보고 상태 `VERIFIED`, HTTP 200. `independentTransportVerification=false` — 별도 서버 검증으로 과장 금지
- 중요 결론: 최초 정적 UI 표시보다 요청 과부하/재시도/외부 데이터 연결의 지연 및 미수신이 우선 병목

## 수정 원칙
1. 중계가 **검증된 `RELAY_BUSY` 503/ `RELAY_RATE_LIMIT` 429**를 반환한 경우에만 유휴 대기와 읽기 동시성 축소를 적용
2. 원천 자료가 필요하면 계속 조회하며, 임의의 가짜 시세·뉴스로 대체하거나 필요한 데이터를 영구 생략하지 않음
3. 동일 URL·같은 세션은 기존 합류 캐시 재사용; 세션/경로 변경 시 오래된 요청을 새 세션에 적용하지 않음
4. 인증, 주문, 저장, 복구 요청을 자동으로 재시도하거나, 다른 GAS·운영 API로 우회하지 않음
5. Worker/GAS/Sheets/Properties 및 운영 `main`/`release/pages` 변경 금지; CI 성공 전 개발 사이트 재게시 금지

## 배포 후 재검증 완료 기준
- 최신 커밋의 Node/Python/Chromium 합성 회귀 모두 PASS
- 개발 프런트엔드 게시 후 `development-only.json.sourceCommit`을 실제 게시 SHA와 일치 확인
- Fold6로 홈 → 시장 → 산업·테마(한국/미국) → 뉴스 → 계좌 → 홈 이동, 새로고침, 로그아웃·재로그인
- `검증·진단`에서 **새 세션**의 `RELAY_BUSY` 횟수·미복구 오류·완료/취소 메뉴 시간 비교; 503의 추가 발생이 있는지 확인
- 데이터 미수신은 `ready`로 통과시키지 않고 메뉴별 `실제 값+출처/관측시각`, `미수신`, `권한 차단`을 분리
- 실계좌 조회·외부 저장/복구·주문 기능에 대한 합성 브라우저 검증 결과는 실제 기능 검증으로 취급하지 않음
- PC 실측 및 실제 금융 데이터 연결/권한 검증은 후속 별도 게이트
