# MY INVEST V2 — 기존 투자전략 메뉴에 독립 비교 계산기 연결 (격리 개발)

## 목표와 실제 변경

독립 브랜치 `feat/strategy-scenario-integration-isolated`에서 기존 `#/strategy` 페이지의 사용자 동작으로만 가상 단타·스윙 비교 계산기를 표시하도록 연결합니다.
Codex의 NEWS/브리핑 PR #8과 운영 브랜치는 건드리지 않았습니다.

변경된 기존 파일은 두 개뿐입니다.

- `js/page-strategy.js`: 기존 전략 페이지 하단에 `<details>` 형식의 접을 수 있는 비교 메뉴를 추가. 사용자가 펼치면 `MYInvestScenarioComparePanelV1.mount`를 수행하고 닫거나 다른 메뉴로 이동하면 `destroy()`와 DOM 정리를 실행.
- `tools/build_dev_pages.py`: **격리 개발 Pages 아티팩트 생성 중에만** 기존 `page-strategy.js` 앞에 정확히 지정한 5개 자체 호스팅 JS 스크립트를 포함. 불명확한 외부 URL이나 임의 JS 파일을 허용하지 않음.

원본 `index.html`, 뉴스 관련 모든 JS·테스트·문서, NH/GAS/Sheets/Properties, `main`, `release/pages`는 변경하지 않습니다. 어떤 PR도 병합하지 않습니다.

## 사용자 동작

1. 개발 빌드에서 투자전략 메뉴(`#/strategy`)에 진입하면 기존 종목분석·단타/스윙·매매계획 계산기가 그대로 보입니다.
2. 하단 '단타·스윙 위험예산 비교 (가상 · 수동 입력)' 항목을 펼칩니다.
3. 합성 기본값의 별도 화면에서 공통 가용자본, 단타/스윙별 진입·손절·목표·수수료·갭 위험 가정 등을 직접 입력합니다.
4. 잘못된 입력이나 기준 미달은 각 모드에서 분리해 표시합니다. 다른 모드의 계산값이 함께 삭제되지 않습니다.
5. 메뉴를 닫으면 해당 비교 화면만 제거합니다. 다시 열면 합성 기본값으로 시작합니다.
6. 투자전략 이외의 메뉴로 이동하면 도구 인스턴스를 정리합니다. 뒤로 돌아와도 비교 화면이 자동으로 열리지 않습니다.

## 개인정보·시세·주문 안전

- 비교 계산기에 `ctxRef`·계좌 보유수량·잔고·종목 선택 정보를 전달하지 않습니다.
- 현재 앱의 별도 계좌/종목 분석 기능을 수정하지 않습니다.
- 실시간 시세, 공개 데이터 API, NH, GAS, Google Sheets를 새로 호출하지 않습니다.
- 가상 금액은 같은 통화(KRW/USD)에서만 계산되며 자동 환전하지 않습니다.
- 합성 초기값은 실제 주가나 사용자 자산이 아닙니다.
- 계산기에는 매수·매도 실행 기능이 없고 기존 주문 승인도 발생하지 않습니다.
- `index.html` 소스는 원본 그대로입니다. 정적 비교 모듈은 개발용 빌드에서만 포함됩니다.

## 구현 테스트

- `tests/test_strategy_comparison_dev_bundle.py`: 빌드된 HTML의 스크립트 순서·해시 목록·CSP·원본 인덱스 불변·비밀파일 제외를 확인합니다.
- `tests/browser_strategy_compare_route_v1.py`: 합성 로그인과 PC 1440 / 중간 폭 690 / 폴드6 좁은 폭 344에서 접기·펼치기, 유효하지 않은 숫자 처리, 세션과 저장 상태 유지, 다른 메뉴 이동 및 재진입을 검증합니다.
- 기존 단타·스윙 비교 계산 115개와 이전 브라우저 테스트도 CI에서 실행하여 회귀 여부를 확인합니다.

## 미완료·통합 제한

- 이 브랜치의 연결은 개발 빌드를 통해서만 확인할 수 있습니다.
- 현재 배포된 개발 Pages와 운영 Pages에 이미 반영된 기능이라고 주장하지 않습니다.
- 실계좌 연동, 실제 시세 검증, ETF·파생상품 최소거래수량, 세금·환율·실제 체결 가능성은 개발 범위 밖입니다.
- 운영 적용 및 뉴스 PR #8 이후 최종 병합은 사용자 승인과 충돌 검증이 필요합니다.
