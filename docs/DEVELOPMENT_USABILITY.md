## 오류 분석 및 최소 수정

- 시나리오: `generateScenario`가 시세 누락을 등락률 0.00으로 대체하는
  화면 모듈 오류를 합성 입력으로 재현했다. 중계/GAS/API와 무관하다.
  `js/market.js`에서 유효한 현재값·이전값이 있을 때만 등락률을 계산하고,
  없는 경우 `미확인`을 표시한다. 실제 보합 0.00%는 유지한다.
- `index.html`의 두 표시명만 사실에 맞게 수정했다. 고정 검색어 뉴스는
  개인 보유종목 뉴스가 아니며, 규칙 기반 템플릿은 AI API 분석이 아니다.
  보유종목명 외부 전송이나 새 AI 연결은 구현하지 않았다.
- 로그인/세션/공통 통신, NH Gateway, AccountStore, 테스트 설정은 수정하지 않았다.

## 수행한 확인과 한계

기존에 정상인 인증·반응형·보안 회귀는 다시 실행하지 않았다. 게시된 공개
자산을 사용하는 브라우저에서 아직 확인하지 않은 주요 로컬 UI를 점검했다.
인증정보를 보유하지 않은 실행 환경이므로 해당 화면 점검은 새 브라우저
컨텍스트에 합성 로컬 세션을 사용했다. 실제 GAS 인증 성공으로 기록하지
않았다. 모든 비공개/외부 API 요청을 차단했고 실제 발생 건수도 0이었다.
진단 메뉴의 첫 점검은 합성 중계 주소를 빠뜨린 검사 설정 문제로 중단됐으며,
가짜 유효 주소를 설정한 뒤 나머지 UI를 확인했다. 제품 오류로 분류하지 않았다.

이번 관련 테스트만 실행: `node tests/market-scenario.test.cjs` 4개 PASS.
누락·부분 응답·실제 보합·하락·0/null/NaN/Infinity 입력을 구분한다.
시장 모듈 문법 검사 PASS. 전체 테스트를 수동 재실행하지 않았다.

실제 NH/주문/GAS 요청 0, 계좌 저장 0. 운영 Pages/GAS/Sheets/Properties,
main/release-pages 변경, 신규 프로젝트·인증 환경 생성, PR 병합 없음.
기존 비공개 자료·복구 이력 유지.
