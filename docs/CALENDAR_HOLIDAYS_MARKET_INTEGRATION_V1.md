# MY INVEST V2 — Google 구독 휴일·기념일 + 공식 시장 일정 통합 V1

상태: **별도 개발 검증 브랜치만, 미배포**. 기반 `feat/calendar-codex-dev-bundle-isolated` 커밋 `1850e883f0f1a944758fadb981960c2130c2e4a0`.
현재 사용자의 연결된 Google 캘린더 목록에 한국 휴일 구독 캘린더가 존재하는 것은 확인했지만, **대시보드 브라우저의 Google OAuth는 별도 설정/승인 대상**이다. ChatGPT에 연결된 Google Calendar 토큰은 GitHub/사이트/GAS로 전달하지 않는다.

## 구현

1. 사용자가 켜는 자체 캘린더에서 개인 일정(기존 localStorage), 연례 기념일(매년 반복), Google 구독 일정, 공식 미국 시장 일정표를 함께 볼 수 있다.
2. 다음 구분별 표시 필터: 내 일정·기념일 / Google 일반 일정 / 공휴일·휴장일 / 시장 주요 일정. **모든 글로벌 시장·투자전략 화면에 무조건 추가 노출하지 않는다.**
3. Google OAuth 읽기 전용 범위는 `calendar.events.readonly` + `calendar.calendarlist.readonly`이다. 선택된 Google 기본 달력과 휴일 구독 달력을 1회 월별 조회한다. 다른 민감한 부속 캘린더는 사용자가 체크하지 않는 한 조회하지 않는다.
4. `calendarList.list`로 실제 구독 달력을 확인하고 `events.list`로 선택한 달력의 해당 월 일정을 읽기 전용 조회. 기본 선택은 개인 기본 달력 + 이름에 휴일/holiday가 포함된 구독 달력. 공휴일 여부와 시장 휴장 여부는 Google 일정이라는 이유만으로 인정하지 않는다.
5. 수신 완료 후 5분 동안 같은 월·같은 달력 조회는 메모리 캐시 사용; 종료/연결 해제/토큰 만료 시 자료와 토큰 폐기. 데이터가 빠졌거나 응답에 `nextPageToken`이 있으면 일부 결과라고 표시한다.
6. 개인 기념일(`category=anniversary`)은 `repeat=yearly`를 지원하고, 원본 1건만 보관한다. 2월 29일 기념일은 윤년일 때만 노출. ICS 내보내기/가져오기는 정확한 `RRULE:FREQ=YEARLY`에 한해 왕복 가능하다.
7. 공식 시장 일정은 출처를 명시한 고정 스냅샷에서 보며, 원본 URL과 마지막 확인일 `2026-11-22`를 표시한다. 시각이 공식 확인된 CPI/고용/PCE, NYSE 조기폐장만 미국 동부→한국 시각 변환. FOMC 결정 시각은 검증되지 않았으므로 임의로 입력하지 않는다.
8. 사용자가 선택해 **‘이 달 공식 시장 일정 .ics 내보내기’**를 누르면 일정과 공식 출처 URL·확인일을 포함한 Google 호환 `.ics` 파일을 내려받는다. 이 기능은 Google 계정에 아무것도 기록하지 않고, 사용자가 Google 캘린더에 직접 가져올 때만 복사된다.

## 데이터 기준과 위험 통제

- **원천 스냅샷 ≠ 실시간 검증.** 확정된 실제 휴장/조기폐장/지표 발표 여부는 출처 원문을 확인해야 한다. 스냅샷에는 과거 수정 이후 최신 변경이 아직 미반영일 수 있다.
- 미국 휴장/회의의 날짜는 **미국 동부 현지일**을 기준으로 달력에 표시한다. 정확한 시간대가 발표되지 않은 FOMC는 임의로 한국 날짜로 이동시키지 않는다.
- Google 구독 달력의 '크리스마스 이브'나 '섣달 그믐' 같은 행사는 기념일일 수 있으며 법정 공휴일·KRX 휴장일이 아니다.
- 한국거래소 공식 휴장일은 KRX 원천 확인 없이는 자동 생성하지 않는다. 현재 한국 휴일 구독만으로 KRX 휴장으로 판단하지 않는다.
- **BLS/BEA/연준의 공식 발표 시간은 소스에서 확인된 경우만 KST로 변환**한다. 주식 자동주문·매수추천 신호로 사용하지 않는다.
- 사용자 캘린더 선택·토큰·가져온 일정은 브라우저 메모리에서만 유지; Google/거래소로 쓰기 요청 없음. 기존 수동 일정만 명시적 등록·수정·삭제 시 브라우저 localStorage에 저장한다.
- 특정 종목 실적 발표/배당락, 국내 CPI, KRX 휴장, 추가 2027년 경제지표는 별도의 공식 데이터 공급/기준일 검증이 필요하다. 현재 자동 취합이나 최신화가 완료되었다고 주장하지 않는다.
- 지정된 기존 개발 빌드 `--include-calendar` 옵션에서만 추가 JS가 포함된다. 운영 GAS/Sheets, `main/release/pages`, 기존 개발 Pages의 자산을 직접 게시·변경하지 않는다.

## 출시 전 남은 요구

1. 사용자가 소유한 Google Cloud 프로젝트에서 Calendar API 활성화, 웹 OAuth client ID와 허용 JavaScript Origin 등록, 필요한 읽기 전용 범위 승인.
2. 실제 개발 사이트에서 해당 Google OAuth 인증 성공과 개인/구독 달력 읽기·이벤트 권한을 수동 검증. **현재 ChatGPT 연결과는 별개 인증**.
3. KRX 공식 휴장일·추가 시장 발표일의 검증된 원천/자동 재검증 경로 구축과 사용자 선택식 알림 정책 정리.
4. 운영 사이트 게시 및 Google 이벤트 자동 쓰기/양방향 동기화는 별도의 명시적 검토와 승인이 필요.
