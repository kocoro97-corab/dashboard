## R-01 / 우선순위 1 — 평가액 0인 계좌의 손실 누락

- **담당/대상:** ChatGPT, `js/page-accounts.js`의 `rowsFor`, `panel(...,'profit')`.
- **재현:** 합성 NH 두 번째 계좌에 평가금액 0, 매입원가 100, 평가손익 -100인
  보유종목 1개를 둔다. 전체 집계에는 -100 손실이 반영되지만
  ‘계좌별 평가손익’ 차트에는 ‘일반계좌 2’가 나타나지 않는다.
- **원인:** 도넛용 `valueKrw>0` 필터를 손익 차트에도 공통 적용한다.
- **수정 요청:** 도넛의 양수 분모 조건과 손익 비교의 행 선택을 분리한다.
  평가액0/음수 손익/미확인 평가액에서 확인된 손익이 있을 때의 정책을 명시한다.
- **완료 기준:** 원본 summary와 차트가 같은 손익 범위를 설명하고 0평가 계좌의
  확정 손실이 숨지 않아야 한다. 저장자료·환산 로직은 수정하지 않는다.

## R-02 / 우선순위 1 — 가장 큰 종목이 집중도 차트에서 누락

- **담당/대상:** ChatGPT, `js/page-accounts.js`의 `panel(...,'value')`.
- **재현:** 검증된 종목 13개를 순서대로 둔다. 1~12번 평가액은 각1,
  마지막 `100013`의 평가액은1000. 합계1012 중 약98.8%인 마지막 종목이
  ‘종목별 평가액 집중도’ 차트에 없고 앞의 12개만 나타난다.
- **원인:** 원본 순서에서 `rows.slice(0,12)`하며 평가액 내림차순 정렬이 없다.
- **수정 요청:** 새 배열에서 평가액 기준 정렬 후 상위 범위를 선택한다.
  생략된 개수/기타와 분모를 명시하고 원본 배열을 변경하지 않는다.
- **완료 기준:** 최대 보유종목은 항상 포함되며 위험 경고와 차트가 모순되지 않는다.

## R-03 / 우선순위 1 — 미보유 국내 종목의 USD 응답 수용

- **담당/대상:** ChatGPT, `js/page-stocks.js`의 `analyze` 응답 검증.
- **재현:** 보유 목록에 없는 합성 국내 코드 `555555`를 검색한다.
  심볼 `555555.KS`, 통화 `USD`, 정상형태70봉 응답을 반환한다.
  ‘555555 · 기술적 분석’이 정상 완료된다. 어느 실제 종목/계좌도 조회하지 않았다.
- **원인:** 통화가 세 글자인지 확인한 뒤 `holdingsFor(sym).rows`와만 비교한다.
  보유 행이 없으면 국내 시장 KRW 조건이 적용되지 않는다.
- **수정 요청:** 검증된 상장 시장/조회 대상의 통화 조건을 보유 여부와 독립시킨다.
  `.KS/.KQ`의 KRW 일치를 강제하고 상장 마스터 시장과 응답 거래소도 확인한다.
  해외 티커의 통화를 근거 없이 USD로 추측하지 않는다.
- **완료 기준:** 국내 USD 응답은 결과를 지우고 분석 불가로 표시한다.
  보유 여부·누락/잘못된 메타와 무관하게 동일한 검증 경계를 적용한다.

## R-04 / 우선순위 1 — 미래 관측 봉으로 분석 완료

- **담당/대상:** ChatGPT, `js/page-stocks.js`의 timestamp/OHLCV 정규화.
- **재현:** `GOOG`와 USD 메타는 일치시키고 70개 timestamp를 모두
  현재 시각+1일~70일로 둔다. 유효 OHLCV 숫자와 함께 반환하면 분석 완료된다.
- **원인:** timestamp를 `t>0`만으로 거르고 미래/유효시간/정렬 여부를 확인하지 않는다.
- **수정 요청:** 허용 시계 오차, 유효 epoch, 봉 순서/중복, OHLC 범위를 검증하고
  유효봉 부족 시 미확인으로 처리한다. Date의 표현 범위 밖 값도 안전하게 거부한다.
- **완료 기준:** 미래 봉을 실제 관측값으로 표시하지 않고 정상 과거 봉은 유지한다.

## 재현 실행 및 증거

기존 테스트 venv·Playwright를 사용한다. 새 인증/Google 환경은 필요 없다.

```bash
PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/myinvest-playwright \
  .venv-ci-https/bin/python tests/browser_commit_review.py --output /tmp/commit-review
```

위 명령은 합성 서비스로 21개 시나리오×3개 화면 크기를 실행하며 현재는 12 FAIL로
종료 코드1을 반환한다. `report.json` 및 합성 계좌 화면 캡처를 남긴다.
`--published` 옵션은 실제 개발 HTML/JS를 읽되 서비스 API는 합성으로 유지한다.
이 모드도 실제 NH/GAS 검증이 아니다. 로그아웃 중 대기 응답 시나리오도 포함한다.
