# MY INVEST V2 — P4 통합 보류 목록 (Codex 지시문 아님)

작성 목적: Codex가 기존 중계/실데이터 검증을 수행하는 동안 **파일 충돌 없이 독립 개발**한 결과와 후속 통합 필요사항을 보존한다. 사용자가 나중에 "코덱스 지시문 작성"을 요청할 때 현재 브랜치 및 기존 Codex 작업 결과를 먼저 점검한 뒤 이 목록을 재검토한다.

## 현재 책임 및 충돌 방지

- Codex 진행 영역: `relay/`, `relay/worker/`, `js/dev_market.js`, `js/transport.js`, `js/read-status.js`, `js/dev_connect.js`, 기존 `js/page-*.js`, 각종 개발 Pages/실데이터 브라우저 테스트, 개발 Worker 배포 검증.
- 이 목록에서 작업 중인 GPT의 독립 영역: `js/strategy-evaluation-v1.js`, `js/strategy-evaluation-review-v1.js`, `tests/strategy-evaluation-v1.test.cjs`, `tests/strategy-evaluation-review-v1.test.cjs`, `docs/P4_*.md`.
- 독립 소스 브랜치: `feat/p4-strategy-evaluation-isolated`; 보조 CI 브랜치: `fix/p4-strategy-evaluation-isolated`.
- 운영 main, release/pages, GAS, NH 실계좌, 실제 주문, 개발 Worker 설정 및 Pages 게시 **변경 금지**.

## GPT에서 이미 구현한 독립 기능

- 순수 일봉 스윙 과거검증: 확정 종가로 신호 평가, 다음 거래일 시가에 진입.
- 한 번의 최대 위험/배분 제한, 수수료와 슬리피지, 갭 손절, 동시 손절·목표 발생 시 보수적 손절 우선 처리.
- 진입·청산 시각과 계획 위험·실제 손익, 위험 초과 표시, 실현손익만을 사용한 기본 성과.
- 별도 위험 검토: 일별 종가 기준 보유 중 가상 청산 평가액, 실현손익 낙폭과 다른 평가손익 낙폭.
- 동일 종목 100% 매수보유와 비용 차감 비교, 데이터/원천 검증 부재 및 투자 노출 불일치 경고.
- 거래 횟수와 승률의 표본 불확실성: Wilson 95% 수학적 참고범위(거래 독립성 가정/성과 보장 불가)를 명시.
- 동일 종목의 100% 보유 대비 외에 **최대 배분비율에 한정한 고정보유 비교**를 추가. 두 비교 모두 실제 노출·기간이 달라 알파나 유의미한 초과수익으로 판정 금지.
- 새로운 독립 `js/strategy-series-quality-v1.js`는 KR/US 일봉 구조·시장 식별·중복 거래일·거래량·대형 가격 급변·수정주가 방식 누락을 검사하고, 모두 확인되지 않으면 과거검증 진입을 보류. `tests/strategy-series-quality-v1.test.cjs`와 `docs/P4_SERIES_QUALITY.md` 포함. 이 모듈은 원천 진위 자체를 검증하지 않음.
- 기존 결과와 OHLCV가 실제 일치하는지 독립 결정적 재실행으로 점검, 가짜 거래 내역 불허.
- 합성 데이터 테스트. **실제 수신 시세 또는 실전 성과 검증은 미실시.**

## 별도 세션 1시간 변경 대기 (아직 Codex에게 지시하지 않음)

- 개발용 60분 세션 소스: `feat/dev-hour-session-isolated` (`js/auth.js`, `gas/Security.gs`, `tests/dev-hour-session.test.cjs`, `docs/DEV_HOUR_SESSION_POLICY.md`).
- 화면과 격리 GAS 서버 양쪽을 동시에 적용해야 실제로 60분 사용 가능. 소스만 반영된 상태라 개발 사이트 실사용은 기존 5분 유지.
- 운영 GAS·운영 웹은 5분, 절대 8시간 제한 유지. Codex가 Worker/실데이터 문제를 해결한 후 배포 절차 충돌을 먼저 점검.
- 사용자가 Codex 지시문을 요청하기 전에는 지시하지 않음.

## Codex 작업 완료 후에만 검토할 후속 통합 후보 (아직 지시하지 않음)

1. **소스 통합:** Codex가 실제 변경한 파일·커밋·CI 결과를 확인하고 P4의 신규 파일만 병합 또는 cherry-pick 가능한지 충돌 점검. PR #7 미병합 유지 및 운영 보호.
2. **일봉 원천 어댑터:** 미국/한국 종목의 OHLCV 식별자·거래소·통화·관측일·타임존, 확정 일봉 여부, 정규장 여부, 수정주가/배당 처리 규칙을 명시한 읽기 전용 어댑터. 샘플 데이터가 아닌 실제 원천 수신 결과로 검증.
3. **시계열 무결성:** 동일 종목 한 통화/거래소만 선택, 중복 거래일 제거, 일봉 간 간격·누락·분할/액면변경·역분할·상폐/생존편향 처리, 시장 벤치마크는 종목 거래일과 정확히 일치시키거나 미비 시 표시 보류.
4. **사후검증 구간 설계:** 전략 조건 고정 후 미래/후행 평가기간을 실제로 분리. `testStartAt`만 기입한 것을 독립 외표본 검증 성공으로 호칭 금지. 30회 미만 거래 시 표본 부족 경고.
5. **독립 성과확인:** 원천 데이터 재계산 대조, 진입/손절/갭·수수료 정합성, 동일종목 보유 대비 비용·노출 차이, 종가 기준 최대 낙폭과 장중 최대 낙폭의 차이 표시.
6. **화면 통합:** 승인된 신규 읽기 전용 분석 패널(화면 설계 후 적용)에서 검증 시각, 샘플 수, 거래 횟수, 비용 가정, 성과·손실 범위를 표시. 실시간 AI 매수 확률/보장 수익/실제 주문 화면으로 오인시키지 않음.
7. **실환경 검증:** PC/Fold6 에뮬레이션과 실기기를 구분; 모바일 장표/표 오버플로, 장기간 표본 성능, 실제 공개 데이터 레이트리밋과 무관한 재사용 가능성, 기존 회귀 검사, 실제 NH 호출 0·저장/주문 0 확인.
8. **게시 승인 경계:** Codex가 진행 중인 Worker 배포 및 게시와 충돌 방지. 모든 통합 테스트가 PASS이더라도 운영 반영은 사용자 별도 승인 전까지 금지.

## 통합 시 반드시 남길 제약

- 기존 P4는 **일봉 기반 스윙 전략의 순수 가상 평가**이며 단타 분봉/VWAP 전략을 검증하지 않는다.
- 브라우저 내 공개 데이터의 실시간성과 백테스트에서 사용한 종가 데이터의 시점은 다르다.
- 원천 수정주가, 분할, 배당, 생존편향 및 청산 유동성이 해결되지 않으면 실제 수익률 검증 PASS를 주장하지 않는다.
- 백테스트의 동일 종목 매수보유 수익률과 위험예산 기반 전략의 수익률은 노출이 서로 달라 차이를 `alpha`로 표시하지 않는다.

## 사용자가 추후 요청한 경우

사용자가 "코덱스 지시문 작성해줘"라고 요청하기 전에는 **이 문서를 근거로 Codex 지시문을 작성하거나 Codex 작업 파일을 수정하지 않는다**. 요청 시 그때의 실제 Codex 작업 결과를 확인한 후 중복·충돌 없는 지시서만 제시한다.
