# 외부계좌 현재가 수정본 적용

이 수정본의 GitHub Pages 기본 GAS 주소는 사용자가 제공한 배포 주소로 변경했습니다.
해당 주소의 `appVersion` 요청에서 `success: true`, `version: v7` 응답을 확인했습니다.
이는 웹 앱에 접속할 수 있다는 확인이며, NH 인증이나 잔고 조회 성공을 뜻하지는 않습니다.

## Apps Script에 적용

1. 기존 `Nhplug.gs`를 백업합니다.
2. 이 폴더의 `Nhplug.gs` 전체를 Apps Script 프로젝트의 같은 파일에 붙여넣고 저장합니다.
3. **배포 → 배포 관리 → 대시보드가 사용하는 웹 앱 → 수정(연필) → 새 버전 → 배포**를 선택합니다.
4. 기존 배포를 업데이트해 `/exec` 주소를 유지합니다.
5. 대시보드를 새로고침하고 로그인한 뒤 일반계좌와 외부계좌 현재가를 조회합니다.
6. 정리된 종목명·코드를 확인한 뒤 **인식자료 저장**을 눌러 Sheets에도 반영합니다.

첨부된 기존 `Code.gs`의 요청 분기는 이 수정본과 호환됩니다. 이 저장소에는 개인 설정이 들어 있는
`Code.gs`를 추가하지 않았습니다. 진단 버전 표기도 맞추려면 해당 파일의 `appVersion` 응답에서
`version:'v7'`을 `version:'v9'`으로 변경하고 같은 배포의 새 버전으로 배포하세요.

## 변경 내용

- 최근 5분 이내에 같은 로그인 세션에서 조회한 NH 일반계좌의 국내주식 현재가를 재사용합니다.
- 나머지 종목은 NH 현재가 API로 조회합니다. 미확인 종목코드를 임의로 추측하지 않습니다.
- NH 공식 명세의 `stck_prpr`을 우선하고, 배열 응답과 기존 가격 필드도 지원합니다.
- HTTP/API 오류, 다른 종목코드 응답, 비정상 가격은 현재가로 사용하지 않습니다.
- 새 조회에 실패한 종목은 이전 가격을 제거하고 부분 합계로 표시합니다.
- OCR 원문은 기본 접힘으로 표시하고, 현금·신용 등 오인식 행을 제외합니다.
- 종목명·코드가 자동 정리되면 저장 버튼을 표시합니다. 저장 전에는 Sheets 원본을 변경하지 않습니다.

Chromium의 344px 및 690px 화면에서 모의 API로 일반계좌 연동, 오류 표시, OCR 접기,
정리된 저장 요청을 확인했습니다. 실제 NH API 호출과 Sheets 저장은 사용자 배포 환경에서 확인이 필요합니다.
