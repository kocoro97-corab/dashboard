# GAS 배포

보안 수정 이후에는 **GitHub Actions → Deploy verified Nhplug to Google Apps Script → Run workflow**로 배포합니다.
기존 웹 앱 배포 ID와 URL을 유지하고 복구 버전 생성, 소스 일치, 보안 진입점 응답을 검증합니다.

개인 설정이 들어 있는 Code.gs와 비공개 보유자료는 저장소에 올리지 않습니다.
배포 도구가 기존 Code.gs를 메모리에서 점검·변환하고 다른 프로젝트 파일을 보존합니다.
Security.gs만 구버전 Code.gs에 수동으로 추가하면 진입점 이름이 중복될 수 있으므로 개별 복사 대신 워크플로를 사용하세요.

기존 계정은 재로그인이 필요합니다. 짧은 비밀번호는 변경 화면을 통해 12자 이상으로 바꿉니다.
이전 기본 관리자 비밀번호는 차단되므로, 해당 경우에는 시트 소유자가 Users 시트에서 새 비밀번호를 먼저 설정해야 합니다.
기존 평문 비밀번호는 성공한 로그인 시 해시로 자동 전환됩니다.

문제와 조치, 남은 제약은 [보안 수정 내역](../docs/SECURITY.md)에 기록했습니다.
